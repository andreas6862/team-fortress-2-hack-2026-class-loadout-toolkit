## 🎯 Using the Toolkit

### 🧢 Class Profiles

Class profiles are where you keep your main information for each class. Use them to store your preferred role, usual playstyle, and any reminders you want to see before a match. You can create separate profiles for different moods or team needs, such as a defensive profile and an aggressive profile. Keeping profiles separate makes it easier to switch plans without rewriting notes each time.

### 🔫 Weapon Loadouts

Weapon loadouts let you save gear choices for each class. Add the weapons you use most, note why you chose them, and keep alternative setups for different maps or team compositions. Loadout pages are useful when you want to compare options quickly or remember a setup that worked well in a previous session.

### 🗺️ Map Notes

Map notes are short reminders attached to maps. Use them for route ideas, callout names, hold positions, flank timing, or anything you want to remember when the map appears. Notes are meant to be quick to read. Keep each note short and focused so it is easy to scan between rounds.

### 🎯 Manual Aim Practice

Manual aim practice gives you a place to plan and record focused warm-ups. Set a practice routine, track how long you spent, and write down what felt difficult. The aim practice section is not a replacement for playing the game. It is a simple way to keep your warm-up consistent and to notice which aiming habits you want to improve.

### 📊 Match Tracking

Match tracking is for recording what happened in a session. Add the map, your class, the result, and a short observation. Over time, these records become a personal history of maps and classes. You can use them to see which maps you play most, which classes you choose under pressure, and which sessions felt strongest.

### 📈 Gameplay Analytics

Gameplay analytics turns your saved match and practice records into a review view. Use it to look for patterns: maps where you perform well, classes you avoid, or practice routines that lead to better sessions. The analytics section is meant to be practical. It highlights trends so you can make one small change at a time.

## 🛠️ Configuration and HUD Tips

The toolkit is organized with TF2 cfg and TF2 HUD users in mind. Keep your class notes and loadout plans in the toolkit, and keep your actual game configuration files in their normal location. When you update a cfg or HUD, add a short note in the toolkit so you remember what changed. This makes it easier to return to a setup later and understand why it was changed.

Use clear names for profiles and loadouts. Short names such as “Scout Warmup” or “Payload Defense” are easier to scan than long descriptions. If you play with more than one HUD or cfg setup, mention the setup in the notes so you can match the right plan to the right configuration.

## 🧭 Tips for New Users

Start with one class and one loadout. Add more only after you have used the first ones for a few sessions. Keep map notes short and specific. Record match results soon after a session while the details are still fresh. Review analytics once a week instead of after every match. This keeps the toolkit useful without turning it into extra work.

If you are unsure where to begin, open the class profiles section and create a profile for the class you play most. Then add one weapon loadout and one map note. That small setup is enough to start using the toolkit regularly.
